#Biblioteca

Este repositório contém uma aplicação para gestão de uma biblioteca.

### Funcionalidades Disponíveis

* `registrar_livro` — Regista um novo livro no sistema
* `listar_livros` — Exibe a lista completa de livros
* `procurar_por_autor` — Pesquisa livros por autor
* `alternar_emprestimo` — Altera o estado de empréstimo de um livro
* `remover_livro` — Remove um livro do catálogo
* `estatisticas` — Mostra dados estatísticos da biblioteca
* `sair_aplicacao` — Encerra a aplicação


## 🎯 Objetivo do Projeto

O objetivo deste projeto foi aprofundar os conhecimentos em Python, com foco na estruturação de código através do uso de funções.


## 📁 Estrutura do Projeto

* `app.py` — Ponto de entrada (ficheiro principal) para executar a aplicação.
* `menu.py` — Gestão da interface visual do menu e navegação.
* `livros.py` — Funções principais para manipulação e gestão do catálogo de livros.
* `auxiliares.py` — Funções de suporte e utilitários secundários.
